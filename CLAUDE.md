# FoodFlow

## Project

FoodFlow is a restaurant management and food ordering application.

The repository contains backend and frontend applications. Backend-specific instructions are in `src/backend/CLAUDE.md`.

## General Rules

* Understand existing code and patterns before making changes.
* Prefer existing project conventions over introducing new patterns.
* Keep changes focused on the requested task.
* Do not refactor unrelated code.
* Do not make architectural changes without discussing them first.
* Reuse existing abstractions where appropriate.
* Do not duplicate functionality that already exists.
* Do not commit or push changes unless explicitly asked.

## Learning Context

This project is also used as a learning project.

When a meaningful design or architectural decision is involved:

* Explain the reasoning and trade-offs.
* Prefer teaching the existing implementation pattern.
* Do not silently introduce a significantly different approach.

For straightforward changes that follow an existing pattern, implement them without unnecessary discussion.

## Verification

After making changes:

* Build the affected project(s).
* Run relevant tests when available.
* Check for compiler errors and warnings introduced by the change.
* Do not claim a change is verified without actually checking it.
